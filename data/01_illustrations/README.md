# Illustration masters

Source PNGs for article heroes and hub art. **Do not edit synced copies** under `content/images/` — run `make sync-images` instead.

## Layout

| Folder / file | Purpose |
|---------------|---------|
| `Basic/` | Framework and workflow diagrams |
| `Agents/` | Agent orchestration art |
| `Governance/` | Governance and memory diagrams |
| `Memes/` | Diagnostic / opinion visuals |
| `Selfpromo/` | Hub ecosystem map, promo heroes |
| `Satori/` | Build-time Satori masters (1600×900); generated by `npm run build:satori`, committed for offline builds |
| `h1.png` | Homepage hero diagram raster (embedded in Satori `homepage-hero-frame`; synced to `content/images/hub/hero.png` via `Satori/hub-hero.png`) |
| `author.jpg` | Founder headshot (synced to `content/images/author/tomas-staniulis.jpg` via `make brand-assets`) |

Mapping: [`data/illustrations.yaml`](../illustrations.yaml). Script: [`scripts/sync_illustrations.py`](../../scripts/sync_illustrations.py).

## Satori vs hand-authored masters

For new article heroes, prefer **hand-authored PNGs** in `Basic/`, `Agents/`, or `Governance/` when a bespoke diagram exists. Use **`generator: satori`** in `illustrations.yaml` when you need a brand-consistent title card without a custom illustration — set `template` to a module in `data/og/templates/` and `source: Satori/{slug}.png`. Default template for new posts: **`category-default`** (parametric per Pelican category). Run `npm run build:satori` before `make sync-images`.

**Playground-first:** preview a single slug without writing PNGs:

```bash
npm run build:satori -- --slug your-slug --dry-run
```

**Per-article OG:** manifest rows with `usage: [hero, og]` generate `Satori/{slug}-og.png` (1200×630) via `article-og` template; sync copies to `content/images/articles/{slug}/og.png`. Article pages prefer dedicated OG over hero crop when slug is in `OG_ARTICLE_SLUGS`.

## Large repos

If this tree exceeds ~50 MB, track with Git LFS (`data/01_illustrations/**`) and document in [`docs/DEPLOY.md`](../../docs/DEPLOY.md).
