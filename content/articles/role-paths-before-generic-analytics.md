*Part 2 — after soft launch.* Part 1 covers click-and-do pedagogy: [Click-and-Do Before Slide Decks](/articles/click-and-do-data-analysis-soft-launch/). Agent depth after analysis practice is [3A Before You Build an Agent](/articles/3a-before-you-build-an-agent/).

One "data analysis" course fails six jobs. Sales needs forecasts and pipeline honesty. People teams need retention language without inventing HR metrics. Executives need risk-aware summaries, not another chart dump. When every learner pastes the same generic analyst prompt, the failure mode is polished wrongness that looks like progress.

On **2026-07-25**, **v1.4.7** added six org-role paths on Module 7. The Data Analysis path itself shipped as **v1.4.2**. For hub checkout and Modules 1–6, see [Shipping Prompt Anatomy](/articles/shipping-prompt-anatomy/). Data Analysis (M7–9) is an operator grant, not a checkout SKU. For how this site and the training host fit, start with [The Prompt Anatomy Ecosystem Map](/articles/prompt-anatomy-ecosystem-map/).

## Six roles, one analysis spine

Module 7 teaches the same analysis habits: name sources, structure the ask, verify before an external send. Learners pick an organizational role. Copyable prompts adapt to that path.

| Role path | Primary OUTPUT shape |
|-----------|----------------------|
| **Sales** | KPI read, trend, and forecast language |
| **Marketing** | Channel, sentiment, and campaign readouts |
| **IT / engineering** | Schema, cleanup, and pipeline steps |
| **People / HR** | Funnel, retention, and pulse language |
| **Management** | Executive summary with explicit risk |
| **Other / internal data** | Universal templates with named placeholders |

The spine stays shared so Module 8 checks still make sense. The prompts stop pretending every learner is a business analyst. Six-block fluency from [The Six-Block Prompt System](/articles/six-block-prompt-system/) remains the foundation. Role paths specialize Output and Quality. They do not replace Meta through Advanced.

## Role-fit

Generic analyst copy fails when the job is a sales forecast or an HR retention note. The spine can be sound and the wording still wrong. Role-shaped prompts answer "this does not sound like my job."

Practice stays inside the training product. Owners and the runtime stay on your side: [The Model Is Not the System](/articles/the-model-is-not-the-system/).

## One path, not six badges

Pick the role that matches the job. Collecting all six is checklist theater. A certificate proves practice inside the drills. Name sources and mark a forecast as an estimate before anything leaves the team. That habit is [Grounding AI Outputs](/articles/grounding-ai-outputs/).

Plans and access stay on [plans and pricing](https://www.promptanatomy.app/#pricing). Core assumes Modules 1–6 before this specialization. Checkout does not sell M7–9.

Pick one role path that matches the job. Certificates prove practice depth.
